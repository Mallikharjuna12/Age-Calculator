# 🎂 Age Calculator

A simple and responsive **Age Calculator** built using **HTML**, **CSS**, and **JavaScript**. It calculates the user's exact age in **Years, Months, and Days** based on the selected date of birth.

## 🚀 Features

- 🎂 Calculate exact age
- 📅 Displays Years, Months, and Days
- ✅ Prevents future date selection
- 📱 Responsive design
- ⚡ Fast and lightweight
- 👨‍💻 Beginner-friendly project

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Age-Calculator/
│── index.html
│── style.css
└── script.js
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Select your Date of Birth.
5. Click **Calculate Age**.
